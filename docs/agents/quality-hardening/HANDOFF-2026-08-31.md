## Repo-wide no-module-mocking policy

- `.oxlintrc.json` enables `anti-slop/no-module-mocking` at `error` severity.
- `frontend/package.json` makes the lint command run from the repository root
  over both `frontend` and `scripts`.
- The rule rejects `jest.mock`, `vi.mock`, `doMock`, and
  `unstable_mockModule`, including imported aliases. It does not reject
  ordinary function spies used for a platform boundary.
- A source scan finds no forbidden module-mocking calls in application or test
  code. The only matching strings are intentional invalid examples in the
  rule's own RuleTester fixtures, which are excluded from the application
  scan so the rule can test its own diagnostics.
- Tests use real components, real implementation modules, realistic payloads,
  and typed fetch/service/browser-boundary injection. They do not substitute a
  mock component or mock module.
